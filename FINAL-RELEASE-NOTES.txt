- Cleaned historical root documentation into one README, deployment checklist and this release note.

HISTORICAL BALANCE RECONCILIATION
The application does not automatically rewrite existing customer history because it cannot safely know the intended value of a prior manual entry.

Use the new Admin controls to correct only entries you have verified:
1. Deposit Review -> Correct Credited USD
2. User -> Transactions -> Reverse for an erroneous reversible manual balance adjustment

Both actions preserve audit history.
